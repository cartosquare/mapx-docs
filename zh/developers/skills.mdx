MapX 提供一组 Markdown 技能，教 AI 代理如何编辑图层样式、清洗数据和生成报告。

CLI 用户可以按需加载：

```bash
mapx skill
```

当前技能索引存储在 `source/skills.json` 中。核心技能包括：

- `styles`——渲染器 JSON schema 和 paint key 矩阵。
- `layer-style-editing`——先查后改、增量修改的样式工作流。
- `report-generation`——数据分析和 HTML 报告工作流。
- `data-cleaning`——把表格数据转换为带类型的 GeoJSON。
