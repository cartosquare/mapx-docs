空间操作是 GIS 的分析基石——它们回答 *“什么在什么附近？”*、*“这两个数据集在哪里重叠？”*、*“哪些位置在多个因素下得分最高？”* 这类问题。在传统 GIS 工具中，运行这些操作需要技术培训和手动配置。在 MapX 中，你只需用自然语言描述目标，平台会自动选择、配置并执行正确的操作。

下面介绍 MapX 支持的每种空间操作、适用场景，以及你可以直接使用或改写的示例提示词。常见用例的完整工作流见页面后文。

## 空间操作一览

### 缓冲区分析

缓冲区分析会围绕数据集中每个要素（点、线或面）创建指定距离的区域。结果是一个新的几何图层，显示该半径范围内的所有内容。

**适用场景：** 服务区制图、邻近分析、服务范围规划、监管退让检查。

```text 示例提示词
显示地铁站 800 米范围内的所有咖啡店
```

```text 示例提示词
哪些住宅地块位于拟建高速延长线 200 米范围内？
```

### 空间连接

空间连接根据要素之间的地理关系（如包含或相交），把一个数据集的属性转移到另一个数据集的要素上。结果是对现有数据的丰富，无需手工按键合并。

**适用场景：** 把行政边界（街区、邮编、人口普查区）关联到点数据集；给事件标记所属区域；把人口统计数据与位置记录结合。

```text 示例提示词
为我的每个门店位置附加所在街区名称
```

```text 示例提示词
把人口普查区的收入数据连接到我的客户点
```

### 热力图

热力图把点数据的空间分布渲染成平滑的颜色渐变——高密度或高值区域显示暖色，低密度区域显示冷色。MapX 同时支持基于计数的热力图和基于数值加权的热力图。

**适用场景：** 客户密度制图、事故频率分析、销售集中度、客流可视化。

```text 示例提示词
创建一张全市客户密度热力图
```

```text 示例提示词
按严重程度加权显示配送事故热力图
```

### 叠加 / 相交

叠加分析找出两个数据集在地理上重合的区域。MapX 可以计算交集（只保留重叠部分）和差集（一个图层中存在但另一个图层中没有的区域），生成代表结果的新几何。

**适用场景：** 识别洪水区或保护区内的地块；找出与拟建开发范围相交的人口普查块；把分区图层与土地利用数据结合。

```text 示例提示词
显示我的数据集中哪些地块落在洪水风险区内
```

```text 示例提示词
找出我的配送区域与城市商业区之间的重叠
```

### 选址评分

选址评分——也叫多准则分析——同时根据多个加权因素评估一组候选位置，并为每个位置生成排名得分。你定义准则，MapX 计算综合得分并在地图上可视化。

**适用场景：** 零售选址、设施规划、物流仓库布点、竞争格局分析、加盟区域评估。

```text 示例提示词
按人口密度、与竞品的距离和客流量给这 50 个位置评分
```

```text 示例提示词
根据高速可达性、家庭收入中位数和可用面积给我的候选地点排名
```

### 筛选与样式

筛选把可见要素限制为满足属性条件的那些（例如营收超过阈值、类别等于某个值）。样式控制这些要素的渲染方式——点大小、色阶、不透明度——基于列值。

**适用场景：** 突出营收层级、隔离单个产品类别、跨区域比较表现、为报告或演示准备干净的地图。

```text 示例提示词
只显示营收超过 $500k 的门店，按区域着色
```

```text 示例提示词
筛选出 2020 年后开业的位置，并按月访问量缩放点的大小
```

## 完整工作流

### 创建热力图

热力图不显示单个点，而是揭示事物*聚集*在哪里——暴露原始散点图中看不见的热点、冷区和渐变。MapX 只需一句自然语言提示就能从任何数据集生成热力图，无需图层配置、色带选择或核参数调整。

#### 热力图类型

**密度热力图**显示点聚集的位置，与属性值无关——强度完全由给定半径内点的数量决定。想回答 *“事故最常发生在哪里？”* 或 *“哪些街区的房源密度最高？”* 时使用。

**加权热力图**用数值列调节强度——密集聚类中的点，如果属性值高，会贡献更多热量。当属性的*量级*重要、而不只是存在与否时使用：*“哪些门店位置创造的营收最多？”*、*“哪里每平方米的房产价值最高？”*。在提示词中指定列时，MapX 会自动切换到加权模式。

#### 创建热力图

<Steps>
  <Step title="上传数据集">
    上传包含点数据的 CSV、GeoJSON 或 Excel 文件。MapX 会自动识别位置列（`lat`/`lng`、地址字符串或几何字段），并把原始点渲染到地图上。
  </Step>

  <Step title="提出热力图请求">
    **密度热力图**只需描述你想可视化的内容：

    ```text
    显示全市事故频率热力图
    ```

    **加权热力图**需要指定作为强度的列：

    ```text
    为每个门店位置创建按营收加权的地图
    ```

    ```text
    用 price_per_sqm 列显示房产价值热力图
    ```
  </Step>

  <Step title="调整半径和强度">
    用后续提示微调视觉效果：

    ```text
    把热力图半径增加到 2 公里
    ```

    ```text
    减小模糊半径——我想看到更紧凑、更清晰的热点
    ```

    ```text
    提高强度——热力图看起来太淡了
    ```

    你也可以要求特定色带：*“用蓝到红色阶”* 或 *“切换到紫色渐变”*。
  </Step>

  <Step title="切换到深色底图增强对比">
    热力图颜色在深色背景下最醒目。让 MapX 切换底图：

    ```text
    使用深色底图
    ```

    随时可以切回来：*“使用浅色底图”* 或 *“使用带标注的浅色底图”*。
  </Step>

  <Step title="导出或加入报告">
    对可视化满意后，有两种导出方式：

    - **导出为 PNG**——说 *“把当前地图视图导出为 PNG”*，得到适合幻灯片或文档的静态图片
    - **加入报告**——点击 **导出报告** 生成包含热力图、数据表和 AI 洞察的完整 HTML 报告（见[报告](/zh/concepts/reports)）
  </Step>
</Steps>

### 运行选址分析

传统选址需要 GIS 专家、数天的数据整理和昂贵的软件授权。使用 MapX，上传候选位置，用自然语言描述评分标准，几秒内就能得到带完整评分明细的排名彩色地图。

<Steps>
  <Step title="上传候选位置 CSV">
    准备一个至少包含 `name`、`lat`、`lng` 列的 CSV 文件。你可以包含任何想纳入评分的附加属性——门店面积、租赁成本、客流估算等。

    把文件拖到 MapX 画布上或使用 **上传数据** 按钮上传。MapX 会自动识别位置列，把候选点绘制到地图上。
  </Step>

  <Step title="上传或描述参考数据集">
    选址评分依赖参考图层——你想测量邻近度或重叠度的数据集。可以上传任意组合：

    - **竞品位置**（含 lat/lng 的 CSV）
    - **公交站点**（CSV、GeoJSON 或公开数据集 URL）
    - **人口区域**（带人口属性的 GeoJSON 多边形）

    如果没有文件，可以在对话中描述数据，MapX 会推荐公开数据集，或让你用估算值继续。
  </Step>

  <Step title="让 MapX 给你的位置评分">
    直接在 AI 对话中输入评分标准。请明确写出指标和权重：

    ```text
    给我的 50 个候选地点评分：1 公里内人口密度（权重 40%），
    与最近竞品的距离（权重 35%），
    与最近公交站点的距离（权重 25%）
    ```

    MapX 会自动执行缓冲区计算、空间连接和加权评分——不需要公式或 GIS 命令。
  </Step>

  <Step title="查看评分地图和排名列表">
    MapX 返回两个输出：

    - 一个**彩色地图图层**，每个候选地点按综合得分着色（默认绿色 = 最高，红色 = 最低）
    - 聊天面板中的**排名数据表**，显示每个地点的名称、总分和各准则得分明细

    点击地图上的任意点，查看它的单项得分和各准则表现。
  </Step>

  <Step title="把分析导出为报告或分享地图链接">
    对结果满意后，有两个选项：

    - **导出报告**——生成包含评分地图、排名表和 AI 撰写文字摘要的专业 HTML 报告（见[报告](/zh/concepts/reports)）
    - **分享地图链接**——创建公开或密码保护的实时交互式地图链接

    两个选项都在右上角的项目工具栏中。
  </Step>
</Steps>

#### 细化评分

第一次评分很少是最后一次。用后续提示迭代，无需重新开始：

```text
把人口密度权重提高到 50%，竞品距离降到 25%
```

```text
增加第四个标准：到高速入口的距离（权重 15%）——
按比例重新平衡其他权重
```

```text
把得分低于 60 的地点从排名列表中移除
```

```text
只用芝加哥都会区内的地点重新评分
```

MapX 会保持项目的完整上下文，每次追问都基于上一个结果。你还可以要求自然语言解释：*“为什么 12 号地点得分这么低？”*

#### 输出内容

评分完成后，项目中会有一个 **Scored Candidates（评分候选）** 图层，每个点附加以下属性：

| 列 | 说明 |
|---|---|
| `composite_score` | 加权总分（0–100） |
| `rank` | 所有候选中的排名 |
| `score_population_density` | 人口准则的子得分 |
| `score_competitor_distance` | 竞品邻近度的子得分 |
| `score_transit_distance` | 公交可达性的子得分 |
| `nearest_competitor_m` | 到最近竞品的实际距离（米） |
| `nearest_transit_m` | 到最近公交站点的实际距离（米） |

色带、得分阈值和列名都可以通过后续提示词调整。

### 物流与仓库覆盖

物流团队用 MapX 把原始仓库和客户数据变成可执行的空间情报——可视化配送区域、识别覆盖缺口、评估新仓库选址。全程只需自然语言提示，不需要 GIS 软件或 SQL 知识。

<Steps>
  <Step title="上传仓库位置">
    准备一个至少包含 `name`、`lat`、`lng` 列的 CSV。`capacity`、`region`、`fleet_size` 等可选列可以在后续分析中引用。

    通过 **上传数据** 或把文件拖到地图画布上传。MapX 会自动识别位置列，把仓库渲染成点图层。
  </Step>

  <Step title="生成覆盖缓冲区">
    让 MapX 为每个仓库构建配送覆盖区：

    ```text
    显示每个仓库周围 50 公里的配送覆盖区
    ```

    MapX 为每个仓库创建缓冲多边形并叠加到地图上。你可以一次请求多个半径（例如内圈 25 公里、外圈 50 公里），或在有路线数据时使用车程估算。
  </Step>

  <Step title="上传客户位置">
    上传包含客户或订单目的地数据的第二个 CSV。包含 `customer_id`、`lat`、`lng` 以及与优先级相关的属性——如 `order_volume` 或 `tier`。

    MapX 会把客户绘制为独立图层，并在空间连接步骤中保持两个图层都激活。
  </Step>

  <Step title="识别覆盖区外的客户">
    运行空间连接，找出配送网络之外的客户：

    ```text
    哪些客户在所有覆盖区之外？
    ```

    MapX 用醒目颜色高亮未覆盖的客户，并在对话中返回数量和列表。你可以要求只导出这些记录，或按区域下钻。
  </Step>

  <Step title="优化仓库选址">
    知道缺口在哪里后，让 MapX 建议在哪里增加运力：

    ```text
    我该在哪里增加一个仓库，才能让未覆盖客户最少？
    ```

    MapX 根据未覆盖客户的空间分布，推荐一个或多个候选位置，并按每个位置能覆盖的客户数量排名。你可以通过约束条件迭代：*“建议高速 10 公里内的位置”* 或 *“只在这三个都会区里建议”*。
  </Step>
</Steps>

#### 物流示例提示词

把这些提示词作为起点——按你的数据调整距离、列名和阈值：

```text
显示每个仓库周围 50 公里的配送覆盖区

哪些客户在所有覆盖区之外？

我该在哪里增加一个仓库，才能让未覆盖客户最少？

按客户落在哪个仓库区域着色

显示哪个仓库服务的客户最多

计算每个客户到最近仓库的平均距离

高亮 order_volume > 100 且不在覆盖区内的客户

按区域拆分地图，显示每个区域的覆盖率
```

#### 处理大数据集

处理非常大的全国或全球数据集时，几个技巧能帮你更快、更聚焦地得到结果：

- **先按区域筛选**——在运行空间连接前让 MapX *“只显示东北区域的客户”*，让操作在更小的子集上运行
- **使用边界框提示**——*“只分析芝加哥 200 公里内的客户”* 从地理上限定计算范围
- **图层可见性**——关掉不在分析的图层；MapX 会保留在内存中但停止渲染，让画布保持响应
- **分块上传**——数据集很大时，按区域拆分后分别上传分析

### 房地产市场分析

房地产专业人士用 MapX 把挂牌数据表变成有说服力的空间叙事——绘制房源地图、叠加社区背景、跨区域比较人口特征、交付精致的客户演示。

<Steps>
  <Step title="上传房源 CSV">
    准备包含房源数据的 CSV。MapX 支持地址字符串或显式坐标：

    - 地址方式：包含 `address` 或 `full_address` 列——MapX 会自动地理编码
    - 坐标方式：包含 `lat` 和 `lng` 列，立即渲染

    包含你想筛选或可视化的属性：`price`、`bedrooms`、`sqft`、`property_type`、`neighborhood`、`days_on_market` 等。

    通过 **上传数据** 或把文件拖到画布上传。MapX 会在几秒内识别并绘制所有房源。
  </Step>

  <Step title="生成价格热力图">
    快速了解价值集中在哪里：

    ```text
    为这些房源创建价格热力图
    ```

    MapX 用 `price` 列作为强度生成加权热力图。热区表示高价值聚集，冷色区域显示低价房源集中的地方。你可以继续调整半径、切换色带或按面积标准化。
  </Step>

  <Step title="添加社区背景图层">
    叠加影响买家决策的配套设施和服务：

    ```text
    显示每处房产 1 公里内的学校
    ```

    ```text
    添加 500 米内的公园和绿地
    ```

    ```text
    在我的房源上叠加显示洪水区边界
    ```

    MapX 会获取或接受上传的参考数据集并执行空间连接，为每个房源标注邻近数据，之后你可以据此筛选。
  </Step>

  <Step title="筛选和比较特定细分">
    下钻到与客户最相关的房源：

    ```text
    只显示 3 居室且价格低于 $800k 的房源，按社区着色
    ```

    MapX 一步完成筛选并重新设置图层样式。你可以叠加多个筛选条件、切换着色维度，或要求并排比较两个价格区间。
  </Step>

  <Step title="导出客户可直接使用的报告">
    分析完成后，生成一份专业交付物：

    - 点击项目工具栏中的 **导出报告**
    - 选择要包含的章节：价格热力图、筛选房源地图、社区对比图表和 AI 撰写的市场摘要
    - 下载为 HTML 或分享直接链接

    报告无需任何额外排版即可直接发给客户。完整说明见[报告](/zh/concepts/reports)。
  </Step>
</Steps>

#### 常见房地产提示词

这些提示词覆盖最常见的房地产用例——按需替换成你自己的列名和条件：

#### 客户演示

MapX 报告设计为可直接交付客户——无需额外排版、无需拼截图、无需做幻灯片。点击一次 **导出报告** 就能生成包含分析项目精确视图、图表、筛选数据表和 AI 撰写市场摘要的 HTML 文档。所有套餐的报告都会带项目名称品牌；**Pro 套餐** 可以添加自己的 Logo 并选择自定义强调色，**Enterprise** 提供完整白标。

<Tip>
  针对高端房产演示，导出报告前切换到深色底图。深色底图让彩色图层更醒目，给输出带来高端、建筑感的气质。只需在点击 **导出报告** 前说一句：*“切换到深色底图”*。
</Tip>
