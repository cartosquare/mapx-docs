MapX 的制图功能把地图从“屏幕上的交互结果”变成可以交付的版面。一个版面可以包含地图框、文字、图例、图表、属性表、比例尺、指北针、二维码、细节窗、说明框和来源信息。

当前版本有两套制图路径：

| 目标 | 使用入口 | 适合场景 |
|---|---|---|
| 快速截取当前地图 PNG | **分享** → **社交媒体分享** | 即时分享、汇报和演示 |
| 精确控制纸张、版心和元素 | **进入专业制图台** | A0–A4 规划图、展板、报告插图 |

<Info>
**社交媒体分享**只截取地图并直接下载 PNG，不显示标题、作者、版面缩略图，也不创建版面记录。需要标题、指标、版本、校样或 PDF 时，进入**专业制图台**。
</Info>

专业制图的核心流程是**编辑 → 校样 → 导出**。

<Steps>
  <Step title="打开制图">
    在工作区工具栏选择**制图**，打开当前项目的版面库。
  </Step>

  <Step title="进入版面">
    选择现有版面，或使用加号新建并选择一个模板。
  </Step>

  <Step title="编辑页面和元素">
    通过**添加**放置内容，通过**更多文档操作**打开页面、模板、内容列表和历史。
  </Step>

  <Step title="校验最新草稿">
    选择**导出**，先校验当前草稿。阻断项必须修复；提醒和建议按交付要求处理。
  </Step>

  <Step title="导出">
    校验通过后继续进入导出阶段，选择 MapX 角标、PNG、SVG、标准 PDF 或印刷 PDF/X-4。
  </Step>
</Steps>

## 开始前

制图使用当前项目中的地图状态和图层。开始前请确认：

1. 地图已经显示需要的图层和正确的范围。
2. 图层名称、样式、图例和标注已经整理完成。
3. 如需印刷，确认目标纸张、DPI、出血和印厂要求。

## 快速截取地图

![当前分享面板中的社交媒体截图设置，包括比例、分辨率、取景框、图例和地图选项](/images/layout/zh/quick-capture.jpg)

<Steps>
  <Step title="打开分享面板">
    在工作区工具栏选择**分享**，展开**社交媒体分享**。
  </Step>

  <Step title="选择截图比例">
    选择 3:2、16:9、4:3、1:1 或自适应比例。
  </Step>

  <Step title="选择分辨率">
    选择 1x、2x 或 3x。取景框显示最终范围；框外区域会压暗。
  </Step>

  <Step title="设置成图元素">
    按需要开启图例、图表图钉、保持 3D 视角和无水印，并选择图例位置。
  </Step>

  <Step title="生成">
    选择**生成图片**。浏览器直接下载 PNG，不创建版面、版本或链接。
  </Step>
</Steps>

免费方案的快速截图始终包含 **MapX 角标**。Basic 及以上可以使用**无水印**开关；该开关开启时移除角标。

<Warning>
关闭**保持 3D 视角**时，导出的地图会回到正北、俯视相机。
</Warning>

## 打开专业制图台

你可以从两个位置进入制图台：

- 在工作区工具栏打开**制图**，选择现有版面或新建版面。
- 在**分享**面板选择**进入专业制图台**。

没有工作稿时，MapX 会从当前地图创建一份 A3 制图初稿。

版面库显示当前项目全部专业版面、缩略图和页面规格：

![当前制图版面库，右侧列出项目和版面缩略图、纸张、DPI、比例尺与像素尺寸](/images/layout/zh/layout-library.jpg)

进入版面后，中央是毫米画布：

![当前专业制图台，包含毫米画布、版面工具栏和缩放控制](/images/layout/zh/studio.jpg)

制图台包含这些区域：

| 区域 | 用途 |
|---|---|
| 顶部工具栏 | 返回地图、修改版面名称和编辑锁；直接提供添加、导出和更多操作 |
| 浮动工具面板 | 添加元素、切换模板、查看内容层级和历史版本 |
| 中央画布 | 拖动、缩放、旋转、吸附和对齐元素；标尺和安全区显示实际毫米位置 |
| 右侧检查器 | 编辑页面、位置、内容、数据和样式 |

### 选择模板

打开**更多文档操作** → **模板**，可以从六个可编辑初稿开始：

![新建版面时选择模板，展示六个可编辑版式、用途和页面规格](/images/layout/zh/layout-start.jpg)

| 模板 | 页面 |
|---|---|
| 规划公示图 | A2 横版，主图、图例和公示来源 |
| 评审汇报单页 | A3 横版，主图加证据栏 |
| 研究报告插图 | A4 竖版，标题、范围和来源 |
| 现场展板 | A1 横版，远距离阅读 |
| A3 分析图 | A3 横版，地图、图表和属性表 |
| 社媒 4:5 精排 | 1080 × 1350 |

套用模板会替换当前版式结构。需要保留现有内容时，先保存版本或复制版面。

### 设置页面

打开**更多文档操作** → **版面**进入页面设置。默认先提供 A3 横版、A4 竖版和社媒 4:5 三个快捷选项；展开**高级印刷设置**后可以修改全部参数。

![当前版面与输出设置，默认显示 A3、A4 和社媒 4:5 三个成品选项](/images/layout/zh/page-settings.jpg)

| 参数 | 说明 |
|---|---|
| 纸张 | A0、A1、A2、A3、A4，或 1:1、4:5、9:16、16:9、3:2 和自定义尺寸 |
| 方向 | 横版或竖版 |
| 尺寸与 DPI | 设置页面大小和输出清晰度 |
| 安全区 | 标出建议避开的边缘区域 |
| 出血 | 为需要裁切的印刷交付增加出血 |
| 印刷标记 | 裁切标记、套准标记和色标 |
| 栏网与基线 | 多列内容、表格和严格对齐 |

普通交付使用 sRGB；印刷交付在导出时选择 FOGRA39 · PDF/X-4。

### 添加和编辑元素

在顶部选择**添加**。常用元素直接显示，更多元素分组放在展开区：

![当前添加内容面板，包含地图框、文字、图例、图表、图片、指标、来源和点标注](/images/layout/zh/add-elements.jpg)

| 分组 | 元素 |
|---|---|
| 地图 | 地图框、点标记、区域高亮、范围框、引线 |
| 叙述 | 图表、属性表、指标、说明框 |
| 图形 | 文字、图片 |
| 出版 | 图例、比例尺、指北针、来源、二维码 |

选中元素后，使用右侧检查器编辑：

- **通用**：位置、宽高、旋转、层级、锁定和可见性。
- **内容**：文字、图表、表格、地图或二维码参数。
- **数据**：关联图层、地图框、图表、表格、分析或来源信息。
- **样式**：字体、字号、颜色、背景、边框和透明度。
- **位置约束**：安全区、吸附和相对位置。

拖动画布上的元素时会显示对齐辅助线。按住 `Cmd` 或 `Ctrl` 可以多选，并一起移动、复制或删除。

### 编辑地图框

地图框保存自己的相机和可见图层，不受其他地图框影响。

![当前地图框检查器，可直接设置底图、自动或固定比例尺以及可见图层](/images/layout/zh/map-inspector.jpg)

1. 选中地图框。
2. 在检查器中核对可见图层和底图。
3. 在地图框内拖动或滚轮缩放，调整要交付的地理范围。
4. 按需要开启 3D 相机、保留当前相机或设置固定比例尺。

固定比例尺适合必须比较多张图的场景。比例尺显示 `1:N`；如果地图框尺寸与当前相机冲突，检查器会提示。

### 创建细节窗

选中地图框后，使用选中工具条中的**新增细节窗**，或选择框选/套索模式：

1. 在主地图框内圈出需要放大的范围。
2. MapX 创建一个关联的地图框和范围框。
3. 把新地图框移动到页面目标位置。
4. 检查主图与细节窗是否保持相同底图、图层和比例尺口径。

### 编辑图例

图例绑定一个地图框，并读取该地图框中的可见图层。

- 默认高度会跟随图例内容自动调整。
- 可以切换 1 列或 2 列，以及简约、标准框、通栏横排样式。
- 可以调整字号、色票大小、行距、图层顺序，并隐藏或重命名单个图例项。
- 图例内容溢出时，校样会给出提醒。

### 保存草稿和版本

编辑会持续自动保存到工作稿。顶部保存状态会显示正在保存、已保存、冲突或错误。

- 打开**更多文档操作** → **历史**，选择**保存版本**创建可恢复的版本。
- 历史版本可以恢复到当前草稿。恢复前 MapX 会要求确认。
- 如果同一版面在另一个窗口被更新，可以重新打开最新版本，或另存当前版本。

保存版本不是普通导出的前置条件；它用于保存可回退的版本。

## 运行校样

打开顶部**导出**后，第一步是**校验当前草稿**。也可以从顶部更多操作进入**导出检查**。

![当前校样结果按阻断、提醒和建议列出问题](/images/layout/zh/proof-result.jpg)

校验始终针对最新草稿，不会先用旧版本代替。问题分三级：

| 级别 | 含义 | 处理方式 |
|---|---|---|
| 阻断 | 不能继续导出 | 必须修复 |
| 提醒 | 可能影响交付质量 | 修复或确认风险 |
| 建议 | 可选优化 | 按交付要求决定 |

常见检查包括：

- 地图清晰度是否满足当前页面和输出要求。
- 字体是否缺失或发生回退。
- 图例是否为空、溢出或引用不可见图层。
- 元素是否越出页面或进入安全区。
- 标题、来源、图表或表格是否缺失。
- 多个元素的层级是否清晰。
- QR 链接是否有效。

选择问题可以定位到对应元素。带**修复**按钮的问题会生成可撤销的版面操作；修改后重新校验。

通过最新草稿校验后，即可进入导出阶段。

## 导出

在通过校验的导出面板中：

1. 选择是否显示 **MapX 角标**。
2. 选择 PNG、SVG 或标准 PDF。
3. 需要印刷时，单独选择**导出印刷 PDF**。

![当前导出面板：校验已通过，MapX 角标开启，并提供 PNG、SVG、标准 PDF 和印刷 PDF/X-4](/images/layout/zh/export.jpg)

| 输出 | 说明 |
|---|---|
| PNG | 屏幕、网页和社交发布 |
| SVG | 适合继续编辑版面元素 |
| 标准 PDF | sRGB，适合屏幕、办公文档和一般归档 |
| 印刷 PDF/X-4 | FOGRA39/CMYK 流程，按页面设置处理出血和印刷标记 |

### MapX 角标与水印

MapX 角标是页面右下角的轻量地图图签：

- 角标显示在成品页面右下角。
- 免费方案固定显示角标。
- Basic、Pro 和 Business 可以选择关闭。

**MapX 角标**开关的语义是：

- **开启**：预览和导出文件显示角标。
- **关闭**：预览和导出文件隐藏角标。

免费方案的开关保持开启且不可关闭，并提示升级。快速截图中的对应控件名称是**无水印**，开启它会移除角标。

<Warning>
请避免把关键文字、来源或图例项放在右下角，以免被角标遮挡。
</Warning>

### 印刷 PDF

印刷 PDF 不可用时，请改用标准 PDF，或联系管理员检查印刷输出配置。

## 交付前检查

- [ ] 标题、作者、机构和来源完整。
- [ ] 地图框使用正确图层、底图和相机。
- [ ] 图例与地图框可见图层一致，比例尺和指北针正确。
- [ ] 关键文字在安全区内，右下角没有重要内容被角标覆盖。
- [ ] 地图框 DPI 满足交付要求。
- [ ] 最新草稿校样已经通过。
- [ ] 普通交付使用 sRGB；印刷交付选择正确的印刷格式。
- [ ] 需要回退点时已经保存版本。

## 常见问题

### 为什么导出按钮仍然不可用？

最新草稿还没有通过校验、校验已经过期，或者草稿仍有保存冲突。重新校验当前草稿并处理阻断项。

### 为什么地图框显示低 DPI？

地图框像素低于页面毫米尺寸和 DPI 所需的分辨率。提高页面 DPI、减小地图框尺寸，或重新捕获更高分辨率地图框。

### 为什么字体显示不可用？

当前版面使用了不可用字体。换用可用字体后重新运行校样。

### 为什么看不到 JPEG？

当前导出面板提供 PNG、SVG、标准 PDF 和印刷 PDF/X-4，不提供 JPEG。
