快速获取关于 MapX 最常见问题的答案——从数据安全和支持格式，到套餐额度、取消政策，以及 MapX 与传统 GIS 工具的对比。

<AccordionGroup>
  <Accordion title="我需要懂 GIS 才能使用 MapX 吗？">
    不需要。MapX 就是为非 GIS 用户设计的。你只需用自然语言输入问题或分析请求，MapX 会在后台完成所有空间分析——无需 GIS 培训、专业软件或技术知识。
  </Accordion>

  <Accordion title="我的数据安全吗？">
    安全。你的数据存储在安全云端，每个项目默认都是私有的——除非你通过项目分享、嵌入链接或报告链接显式分享，否则不会公开可见。MapX 不会与第三方共享你的数据。
  </Accordion>

  <Accordion title="MapX 支持哪些文件格式？">
    MapX 支持 **CSV**、**GeoJSON** 和 **Excel**（`.xlsx` 和 `.xls`）文件。上传后，MapX 会自动识别经纬度列——大多数情况无需手动配置。
  </Accordion>

  <Accordion title="MapX 能做 GIS 级分析，而不仅是可视化吗？">
    可以。MapX 执行完整的空间操作，不只是视觉样式。支持的分析包括：

    - **缓冲区**——围绕点、线或面生成距离区域
    - **空间连接**——基于地理关系组合数据集
    - **叠加**——求空间图层的交集或并集
    - **热力图**——点分布的密度可视化
    - **多准则选址评分**——基于加权空间因素排名并识别最优位置
  </Accordion>

  <Accordion title="我可以随时取消套餐吗？">
    可以。你可以在账户设置中随时取消订阅——无需联系客服。取消后，在当前账单周期结束前你仍然可以使用套餐的所有功能。
  </Accordion>

  <Accordion title="如果我的用量超出套餐怎么办？">
    你可以随时在账户设置中升级套餐。升级时所有现有数据和项目都会完整保留——切换过程不会丢失任何内容。
  </Accordion>

  <Accordion title="MapX 能生成专业报告吗？">
    可以。MapX 包含一键 HTML 报告生成。报告自动包含地图、图表、数据表和总结分析的 AI 撰写洞察。白标报告（带你的品牌）在 Enterprise 套餐可用。
  </Accordion>

  <Accordion title="MapX 与 ArcGIS 相比如何？">
    ArcGIS 每用户每年 **\$600+**，且需要专门的 GIS 培训才能有效使用。MapX Pro **\$99/月**，完全在浏览器中运行，无需任何培训或软件安装。对于绝大多数商业空间分析任务——选址、区域制图、邻近分析和报告——MapX 上手更快，门槛显著更低。
  </Accordion>

  <Accordion title="AI 提问限额是多少？">
    提问限额取决于套餐：

    | 套餐 | 每月提问限额 |
    |---|---|
    | Free | 30 次 |
    | Basic | 500 次 |
    | Pro | 5000 次 |
    | Enterprise | 不限 |

    提问次数会在账单日自动重置，你可以在账户设置中查看账单日。
  </Accordion>

  <Accordion title="MapX 能处理大数据集吗？">
    可以。MapX 使用 **GPU 加速的 WebGL 渲染**流畅处理大规模空间数据。你可以可视化和分析**10 万+ 数据点（60fps）**，不会卡顿或性能下降。
  </Accordion>
</AccordionGroup>
