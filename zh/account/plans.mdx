MapX 用 Credits 对 AI 用量计费。每个套餐都包含每月 Credits 额度，以及存储、导出和分享功能——随着工作量增长，你才需要支付更多。计费方式见[Credits](/zh/account/credits)。

## 套餐对比

| 功能 | Free | Basic | Pro | Business |
|---|---|---|---|---|
| **价格** | \$0 / 月 | \$29 / 月 | \$99 / 月 | \$999 / 月 |
| **Credits / 月** | 300 | 3,000 | 12,000 | 150,000（团队共享） |
| **项目数** | 1 | 30 | 300 | 不限 |
| **存储** | 50 MB | 30 GB | 100 GB | 1 TB |
| **静态地图 PNG 导出** | ✓（含水印） | ✓ | ✓ | ✓ |
| **数据文件下载** | — | ✓ | ✓ | ✓ |
| **项目 Manifest 导出** | — | ✓ | ✓ | ✓ |
| **在线托管报告分享** | ✓ | ✓ | ✓ | ✓ |
| **地图链接分享** | ✓ | ✓ | ✓ | ✓ |
| **向其他成员分享项目** | — | — | ✓ | ✓ |
| **团队席位** | — | — | — | 5 |

## 如何选择套餐

- **Free**——适合探索 MapX、熟悉界面或偶尔做小型分析。每月 300 Credits 对轻度试验来说足够。
- **Basic**——适合做常规工作的分析师，需要干净、无水印的导出和更大的项目库。每月 3,000 Credits 可以覆盖大多数个人工作量。
- **Pro**——为重度用户和小团队设计。每月 12,000 Credits、向其他成员分享项目、项目 Manifest 导出和无水印高清静态地图 PNG 导出，是专业空间分析工作的正确选择。
- **Business**——团队套餐，最多 5 个席位共享每月 150,000 Credits 额度池、1 TB 存储和全部 Pro 功能。
