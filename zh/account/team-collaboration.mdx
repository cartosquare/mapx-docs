Pro 和 Enterprise 套餐支持在共享的 MapX 项目上团队协作。协作者不必再反复导出和邮件传输文件，而是在同一个实时项目中工作——基于角色的权限精确控制每个人能做什么。

<Note>
  团队协作需要 **Pro 或 Enterprise** 套餐。Free 和 Basic 套餐支持公开和私有链接分享，但不包含多用户项目协作。
</Note>

## 添加协作者

<Steps>
  <Step title="打开项目设置">
    打开项目后，点击右上角的 **设置** 图标（齿轮），然后选择 **协作者**。
  </Step>
  <Step title="通过邮箱邀请">
    输入要邀请的人的邮箱。对方不需要已有 MapX 账号——接受邀请时会提示创建。
  </Step>
  <Step title="选择角色">
    在角色下拉框中选择 **查看者** 或 **编辑者**。每种角色能做什么，见下方[角色与权限](#角色与权限)表格。
  </Step>
  <Step title="发送邀请">
    点击 **发送邀请**。协作者会收到一封包含加入链接的邮件。
  </Step>
</Steps>

你可以在同一 **协作者** 设置面板中随时管理或移除现有协作者。

## 角色与权限

| 角色 | 查看地图 | 运行分析 | 导出 | 编辑数据 | 管理协作者 |
|---|---|---|---|---|---|
| **查看者** | ✓ | ✗ | ✓（PNG） | ✗ | ✗ |
| **编辑者** | ✓ | ✓ | ✓ | ✓ | ✗ |
| **所有者** | ✓ | ✓ | ✓ | ✓ | ✓ |

- **查看者**——可以查看地图并导出 PNG 快照，但不能运行新的 AI 提问或修改任何项目数据。
- **编辑者**——拥有完整分析权限：运行提问、编辑图层数据、导出结果。不能添加或移除其他协作者。
- **所有者**——对项目拥有完全控制，包括邀请/移除协作者和修改项目设置。项目创建者默认为所有者；所有权可以在项目设置中转移。

## 套餐限额

| 套餐 | 每项目协作者数 |
|---|---|
| Free | —（不可用） |
| Basic | —（不可用） |
| Pro | 最多 **5** 人 |
| Enterprise | **不限** |

如果使用 Pro 且单个项目需要超过 5 名协作者，可以考虑升级 Enterprise，或使用公开/私有链接分享为利益相关方提供只读访问。

## Enterprise 管理员控制

Enterprise 账号包含项目协作之外的集中管理工具：

- **SSO（SAML / OIDC）**——通过你现有的身份提供商（Okta、Azure AD、Google Workspace 等）管理所有 MapX 访问
- **集中用户管理**——管理员可以在单一仪表盘上开通和停用用户、重置权限、管理席位分配
- **审计日志**——追踪谁访问了哪个项目、运行了哪个分析、导出了什么数据——满足合规和数据治理需求
