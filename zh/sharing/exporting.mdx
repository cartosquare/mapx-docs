MapX 支持多种面向不同下游场景的导出格式——把 PNG 放进幻灯片、把富化的 GeoJSON 交给 GIS 管线，或给客户发送一份精美的 HTML 报告。你能使用的格式取决于套餐。

## 按套餐的导出选项

| 导出类型 | Free | Basic | Pro | Enterprise |
|---|---|---|---|---|
| 高清静态地图 PNG 导出 | ✓（含水印） | ✓（无水印） | ✓ | ✓ |
| 在线托管报告分享 | ✓ | ✓ | ✓ | ✓ |
| CSV / GeoJSON 数据下载 | ✗ | ✓ | ✓ | ✓ |
| 项目 Manifest 导出 | — | ✓ | ✓ | ✓ |
| 定时导出 | ✗ | ✗ | ✗ | ✓ |

<Note>
  原始和分析后数据（CSV / GeoJSON）的下载需要 **Basic 及以上**套餐。Free 用户可以查看和分析数据，但不能下载为 CSV 或 GeoJSON。
</Note>

## 导出高清静态地图 PNG

高清静态地图 PNG 导出把地图画布的当前状态捕捉为静态图片，包括所有可见图层、标注和 AI 生成的叠加层。

**步骤：**

<Steps>
  <Step title="打开导出面板">
    打开项目后，点击右上角工具栏的 **导出** 按钮。
  </Step>
  <Step title="选择 PNG">
    在导出格式选项中选择 **PNG 图片**。
  </Step>
  <Step title="选择分辨率">
    选择想要的输出分辨率。打印或大尺寸显示建议使用更高分辨率。
  </Step>
  <Step title="下载">
    点击 **下载**。文件会保存到浏览器的默认下载位置。
  </Step>
</Steps>

<Note>
  Free 套餐的高清静态地图 PNG 导出包含左下角的 **MapX 水印**。升级到 Basic 或更高版本即可移除。
</Note>

## 下载数据

MapX 导出的不只是原始上传——它导出的是**分析后、富化的数据**。运行 AI 分析后，数据集通常会增加新列，例如：

- **评分**（如步行指数、风险评分）
- **缓冲区结果**（如点 500 米内的要素）
- **连接属性**（如连接到位置的人口普查数据）

你可以随时把这个富化数据集下载为：

- **CSV**——用于电子表格工具、BI 平台或进一步处理
- **GeoJSON**——用于消费空间格式的 GIS 工具（QGIS、ArcGIS、Mapbox 等）

数据面板中的每个图层，其行右侧都有一个**下载按钮**。点击即可把该图层的数据下载为 CSV 或 GeoJSON。

## 报告导出

MapX 可以一键生成**HTML 报告**，汇总你的地图、关键发现和 AI 分析叙事——可直接分享给客户或嵌入内部文档。

生成的报告会显示在数据面板的**报告**区域。每个报告行的右侧都有一个**导出按钮**——点击即可下载 HTML 报告文件。

- **Free / Basic**：标准 MapX 品牌报告模板
- **Pro**：品牌化报告（自定义标题、Logo、颜色）
- **Enterprise**：完全没有 MapX 品牌的完整白标报告

报告构建器的完整说明见[报告](/zh/concepts/reports)。

## 导出项目 Manifest

项目 Manifest 把项目的**地图状态和图层配置**——底图设置、图层样式、标注、图例和可见性——打包到一个 zip 归档中的 `manifest.json` 文件。这是备份或迁移项目样式与布局的轻量方式。

**步骤：**

<Steps>
  <Step title="打开项目设置">
    在工作区中打开**设置**面板（齿轮图标）。
  </Step>
  <Step title="点击导出配置">
    在**导出配置**区域点击导出按钮。
  </Step>
  <Step title="下载">
    浏览器会下载包含 `manifest.json` 的 `<项目名>-manifest.zip`。
  </Step>
</Steps>

项目 Manifest 导出在 **Basic 及以上**套餐可用。
