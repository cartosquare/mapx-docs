MapX 支持多种面向不同下游场景的导出格式——把 PNG 放进幻灯片、把富化的 GeoJSON 交给 GIS 管线，或给客户发送一份精美的 HTML 报告。你能使用的格式取决于套餐。

## 按套餐的导出选项

| 导出类型 | Free | Basic | Pro | Enterprise |
|---|---|---|---|---|
| PNG 地图导出 | ✓（含水印） | ✓（无水印） | ✓ | ✓ |
| HTML 报告 | ✓（基础） | ✓（基础） | ✓（品牌化） | ✓（白标） |
| CSV / GeoJSON 数据下载 | ✓ | ✓ | ✓ | ✓ |
| 自定义导出格式 | ✗ | ✗ | ✓ | ✓ |
| 定时导出 | ✗ | ✗ | ✗ | ✓ |

<Note>
  原始和分析后数据（CSV / GeoJSON）的下载在**每个套餐**都可用——无论订阅级别如何，你的数据始终属于你。
</Note>

## 导出 PNG

PNG 导出把地图画布的当前状态捕捉为静态图片，包括所有可见图层、标注和 AI 生成的叠加层。

**步骤：**

<Steps>
  <Step title="打开导出面板">
    打开项目后，点击右上角工具栏的 **导出** 按钮。
  </Step>
  <Step title="选择 PNG">
    在导出格式选项中选择 **PNG 图片**。
  </Step>
  <Step title="选择分辨率">
    选择想要的输出分辨率。打印或大尺寸显示建议使用更高分辨率。
  </Step>
  <Step title="下载">
    点击 **下载**。文件会保存到浏览器的默认下载位置。
  </Step>
</Steps>

<Note>
  Free 套餐的 PNG 导出包含左下角的 **MapX 水印**。升级到 Basic 或更高版本即可移除。
</Note>

## 下载数据

MapX 导出的不只是原始上传——它导出的是**分析后、富化的数据**。运行 AI 分析后，数据集通常会增加新列，例如：

- **评分**（如步行指数、风险评分）
- **缓冲区结果**（如点 500 米内的要素）
- **连接属性**（如连接到位置的人口普查数据）

你可以随时把这个富化数据集下载为：

- **CSV**——用于电子表格工具、BI 平台或进一步处理
- **GeoJSON**——用于消费空间格式的 GIS 工具（QGIS、ArcGIS、Mapbox 等）

下载方法：点击 **导出 → 下载数据**，选择偏好的格式。

## 报告导出

MapX 可以一键生成**HTML 报告**，汇总你的地图、关键发现和 AI 分析叙事——可直接分享给客户或嵌入内部文档。

- **Free / Basic**：标准 MapX 品牌报告模板
- **Pro**：品牌化报告（自定义标题、Logo、颜色）
- **Enterprise**：完全没有 MapX 品牌的完整白标报告

报告构建器的完整说明见[报告指南](/zh/guides/reports)。
