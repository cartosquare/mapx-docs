MapX 里所有分享都基于链接或令牌，查看者**不需要 MapX 账号**。入口有两处：地图、图片与人相关的在**分享**面板，报告链接在**报告**面板。

| 分享什么 | 在哪里创建 | 谁能打开 |
|---|---|---|
| **交互地图**（嵌入） | 分享面板 → **嵌入分享** | 拿到链接或 iframe 的人 |
| **实时视图** | REST API 或 `mapx` CLI | 拿到链接的人 |
| **地图图片** | 分享面板 → **社交媒体分享** | 你发文件给谁，谁就能看 |
| **HTML 报告** | 报告面板 → **复制分享链接** | 拿到链接的人 |
| **项目访问权** | 分享面板 → **项目分享** | 你邀请的同伴 |

## 打开分享面板

**分享**在左侧/右侧工具栏里（和图层、数据、分析同一条）。面板里分三段，都可以折叠：**社交媒体分享**、**嵌入分享**、**项目分享**。

![分享面板的三个分区：社交媒体分享、嵌入分享、项目分享](/images/sharing/share-panel.png)

## 生成分享图片

这一段把当前地图渲染成 PNG，可以直接发帖、贴进幻灯片或放进报告。

<Steps>
  <Step title="选宽高比">
    **3:2**（默认）、**16:9**、**4:3**、**1:1**，或**自适应**（跟随当前视口）。
  </Step>

  <Step title="选分辨率">
    **1x**、**2x**（默认）或 **3x**。下拉里直接写出像素尺寸，它由取景框决定：1200 × 800 的框在 2x 下导出 2400 × 1600。
  </Step>

  <Step title="打开取景预览">
    **取景预览**会在地图上画出截图范围。平移缩放让框覆盖你要的内容，图例可以在框内直接拖动定位。
  </Step>

  <Step title="决定成图里画什么">
    | 选项 | 作用 |
    |---|---|
    | **无水印** | 去掉 MapX 水印。基础版及以上可用；免费版始终带水印 |
    | **保持 3D 视角** | 按倾斜的 3D 相机出图，而不是压成俯视 |
    | **图表图钉** | 把钉在地图上的图表卡片画进成图 |
    | **图例** + 四角选择 | 画上图例，并放在四个角之一 |
  </Step>

  <Step title="生成">
    **生成**在浏览器里渲染，并直接下载为 `mapx-<时间戳>.png`。不上传任何内容，也不产生链接 —— 文件就是你的。
  </Step>
</Steps>

![分享面板的图片分区：宽高比、分辨率，以及决定成图内容的各个开关](/images/sharing/share-image.png)

## 嵌入地图

嵌入把项目发布成一张只读交互地图，可以放到任何网站上。

<Steps>
  <Step title="打开嵌入">
    状态行会显示**嵌入已启用**或已禁用。关闭时嵌入链接不渲染任何内容。
  </Step>

  <Step title="复制链接或 iframe 代码">
    **嵌入链接**是纯 URL；**HTML 代码**是一段现成的 `<iframe>`，默认 `width="100%"`、`height="600"`。
  </Step>

  <Step title="决定观众能操作什么">
    **显示图层列表**与**显示导航控件**控制嵌入页里是否出现图层列表和缩放/指北覆盖层。默认都开；勾选状态会体现在复制出的 URL 里。
  </Step>

  <Step title="预览，必要时重新生成">
    **预览**直接打开嵌入页。**重新生成**会换一个新令牌，**此前复制出去的链接全部失效** —— 链接外泄时用它。
  </Step>
</Steps>

嵌入页跟随项目的主题色与作者保存的地图状态，观众看到的样式和你一致。观众可以平移、缩放、查看要素，但不能编辑。

![嵌入分区：状态、链接、iframe 代码、观众可见选项、预览与重新生成令牌](/images/sharing/share-embed.png)

<Warning>
关闭嵌入会让所有人打不开这张地图，包括已经贴到别人站点里的嵌入。重新生成令牌对旧链接是同样的效果。
</Warning>

## 分享报告链接

报告不在分享面板里，而在**报告**面板：

<Steps>
  <Step title="打开报告面板">
    报告在工作区工具栏里，每一行是一份报告（一个修订版本）。
  </Step>

  <Step title="用行内菜单">
    打开该行的 **⋯** 菜单，选 **复制分享链接**。
  </Step>

  <Step title="把链接发出去">
    剪贴板里会得到一条 URL，任何浏览器都能打开，不需要 MapX 账号。
  </Step>
</Steps>

只有 **HTML** 报告能分享 —— Word 与 PPT 是下载文件，不是链接。反复点复制会复用同一修订版本的同一个令牌，不会堆出一串死链接。

![报告面板的行内菜单，含「复制分享链接」](/images/sharing/share-report-link.png)

## 实时视图与静态视图

网页端产出的是嵌入链接；**REST API** 与 **mapx CLI** 还能为项目产出两种视图链接：

| 链接 | 行为 |
|---|---|
| **实时视图** | 打开地图并保持同步：项目里的改动会实时推到观众端 |
| **静态视图** | 打开同一张只读地图，但不再跟随后续改动 |

```bash
mapx view live <session-id>      # 打印实时视图链接
mapx view static <session-id>    # 打印静态视图链接
```

端点与权限范围见 [mapx CLI](/zh/developers/mapx-cli) 与[API 参考](/zh/developers/api-reference)。

## 把项目分享给同伴

**项目分享**把项目本身授权给另一个 MapX 用户 —— 对方能在自己的控制台里打开并继续在里面工作。

<Steps>
  <Step title="填对方账号邮箱">
    输入已是 MapX 用户的邮箱，点**分享**。
  </Step>

  <Step title="查看已分享列表">
    有权限的人都列在**已分享**下面。
  </Step>

  <Step title="收尾时移除权限">
    用行上的移除按钮即可立刻收回对方的访问权。
  </Step>
</Steps>

项目分享在**专业版**与**商业版**可用。免费版与基础版仍然可以分享地图、图片与报告链接 —— 这几种都不需要对方拥有 MapX 账号。

![项目分享分区：按邮箱邀请，以及已分享列表](/images/sharing/share-project.png)

## 收回访问权

| 要收回什么 | 怎么做 |
|---|---|
| 嵌入链接 | 关闭嵌入，或重新生成令牌 |
| 实时 / 静态视图链接 | 重新生成项目的嵌入令牌（两种链接共用它） |
| 同伴的项目访问权 | 在**已分享**里移除该成员 |
| 报告链接 | 删除那份报告修订版本；链接永远指向某个具体修订 |
