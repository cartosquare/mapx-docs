MapX 提供四种分享方式——报告链接、嵌入地图、社交图片和项目访问权限。所有分享选项都在项目工具栏打开的**分享**面板中。

## 分享类型一览

| 类型 | 分享内容 | 适用场景 |
|---|---|---|
| **报告分享** | HTML 报告的分享链接 | 客户交付物、利益相关方更新 |
| **嵌入分享** | 交互式地图的嵌入链接或 iframe 代码 | 网站、仪表盘、门户 |
| **社交媒体分享** | 高分辨率地图图片 | 社交媒体帖子、演示、文档 |
| **项目分享** | 特定用户的项目访问权限 | 团队协作 |

## 报告分享

生成 HTML 报告后（见[报告](/zh/concepts/reports)），**分享**面板会列出你的报告。对每份报告你可以：

- **生成链接**——创建报告的可分享 URL。
- **复制或打开链接**——通过邮件或聊天发送；接收方无需 MapX 账号即可在任何浏览器中打开。

报告链接是把精美的交互式分析文档交付给客户和利益相关方的便捷方式，不用再发一文件夹截图。

![报告分享面板](/images/sharing/report-share.png)

## 嵌入分享

**嵌入分享**把你的项目变成可以放在任意网站上的交互式地图：

- **启用嵌入**——生成受 token 保护的嵌入 URL。
- **复制嵌入链接或 iframe 代码**——把 URL 粘贴到任何地方，或把现成的 `<iframe>` 代码片段粘贴到你的网站 HTML 中。
- **选择查看者看到的内容**——复制前可以开关图层控件和图层列表。
- **预览**——打开嵌入页面确认效果。
- **重新生成 token**——让之前复制的嵌入链接失效。

任何拥有嵌入链接的人都可以在浏览器中查看交互式地图——平移、缩放、查看数据——无需 MapX 账号。要让项目下线，在分享面板中禁用嵌入即可。

![嵌入分享面板](/images/sharing/embed-share.png)

## 社交媒体分享

**社交媒体分享**生成一张可以直接发布或插入的高分辨率地图图片：

- 为不同平台选择**宽高比**（3:2、16:9、4:3、1:1 或自动）。
- 选择**分辨率**（1x、2x 或 3x），并在地图上预览精确的截图范围。
- 切换**水印**——Free 套餐导出的图片带 MapX 水印，Basic 及以上可以导出无水印图片。

生成的 PNG 会下载到你的设备，可以直接用于社交媒体、幻灯片或文档。

![社交媒体分享面板](/images/sharing/social-share.png)

## 项目分享

**项目分享**把项目本身分享给指定用户：

- 输入接收者的**邮箱**邀请其加入项目。
- 在同一面板中管理访问权限——你可以随时**移除用户**。

项目分享包含在支持团队协作的套餐中。可用性详见[套餐](/zh/account/plans)。
