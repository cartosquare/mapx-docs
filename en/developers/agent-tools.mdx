Integrating MapX with an external agent does not require a per-agent adapter.
Claude Code, Codex, OpenCode, OpenClaw, Hermes, WorkBuddy, and other LLM tool
loops can all use the same skill file. The agent downloads it and follows its
instructions to configure itself.

## One-step integration

Give your agent the skill download link and ask it to install and follow the
skill:

```text
Download https://mapx.oss-cn-hongkong.aliyuncs.com/skill/mapx-skill/SKILL.md
and follow its instructions to install the mapx CLI and configure your API key.
```

The skill file is self-contained. It explains how to:

- download the right `mapx` binary for Linux, macOS, or Windows;
- set `MAPX_API_KEY` (and optional `MAPX_API_URL`);
- verify the setup with `mapx auth status`;
- use commands for projects, layers, styles, map control, view URLs, and
  reports;
- load theme manuals on demand with `mapx skill styles`,
  `mapx skill layer-style-editing`, or `mapx skill report-generation`.

## Fallback when the agent cannot install skills

Some chat-only agents cannot create skill files. In that case, paste the full
`SKILL.md` content into the conversation. It is plain Markdown and is written
to be followed directly from the context.

## Get an API key

Create a personal API key in the **Profile** panel of the MapX app. The full
key is shown only once, so save it immediately. Keys start with `mkx_`.

## Verify the integration

Ask the agent to confirm the connection:

```bash
export MAPX_API_KEY="mkx_..."
mapx auth status
```

Then run a simple end-to-end check:

```bash
mapx session list
mapx session create --title "agent test"
mapx upload ./data.geojson --session <session_id>
```

If all three succeed, the agent can drive MapX projects end to end.
