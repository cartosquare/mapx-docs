---
title: "Developer overview"
description: "Integrate MapX with your own applications through the API, MCP, and skill system."
---

MapX exposes three integration surfaces:

- **API** — the HTTP backend that manages projects, layers, files, reports, and
  billing.
- **CLI** — the `mapx` command-line client that lets AI agents and third-party
  platforms upload data, control projects and maps, edit styles, and save
  reports.
- **Skills** — reusable guidance documents that teach an AI agent how to work
  with MapX data, styles, and reports (loaded via `mapx skill`).

Start with [authentication](/en/developers/authentication), then use the
interactive [API Reference](/api-reference/projects/list-projects) or the
[mapx-cli](/en/developers/mapx-cli).

Note: the API resource is named `session` for historical reasons; it represents
a persistent project in the product (a workspace with map state, layers, files,
chat history, and reports).
