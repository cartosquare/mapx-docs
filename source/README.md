# MapX Documentation Source Pack

This directory is generated by the mapx repository.

Regenerate with:

```bash
pnpm docs:gen
```

Then copy this directory into the docs repository as `source/`:

```bash
cp -r docs-source/* <docs-repo>/source/
```

Also copy the OpenAPI contract to the docs repository root (Mintlify renders it
as the interactive API reference):

```bash
cp docs-source/openapi.json <docs-repo>/openapi.json
```

## Contents

- `api-routes.json` — API endpoints parsed from `apps/api/src/routes/*.ts`.
- `mcp-tools.json` — MCP tool names and descriptions parsed from `tools/crates/mapx-mcp`.
- `skills.json` — skill index parsed from `skills/*/SKILL.md`.
- `system-prompt.md` — copy of the AI system prompt.
- `openapi.json` — OpenAPI 3.0.3 contract for `/api/v1` (generated by `pnpm openapi:gen`).

## Manual supplements

The parsers are intentionally lightweight. If a route is built dynamically or a
tool description cannot be extracted, add the missing entry manually and keep
this README in sync.
