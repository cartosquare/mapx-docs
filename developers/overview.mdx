---
title: "Developer overview"
description: "Integrate MapX with your own applications through the API, MCP, and skill system."
---

MapX exposes three integration surfaces:

- **API** — the HTTP backend that manages sessions, layers, files, reports, and
  billing.
- **CLI** — the `mapx` command-line client that lets AI agents and third-party
  platforms upload data, control sessions and maps, edit styles, and save
  reports.
- **Skills** — reusable guidance documents that teach an AI agent how to work
  with MapX data, styles, and reports (loaded via `mapx skill`).

Start with [authentication](/developers/authentication), then use the
interactive [API Reference](/developers/api-reference) (generated from the
OpenAPI contract), the [mapx CLI](/developers/mcp), or the curated endpoint
overview.
